# User Manual

## Web Interface Usage

1. Open `web/index.html` in your browser
2. Configure map settings (size, obstacle density)
3. Click "Generate Map"
4. Select your desired algorithm
5. Click "Plan Path" to generate a path
6. Click "Execute" to watch the robot move

## Dynamic Obstacle Mode

1. Enable "Dynamic Obstacles" toggle
2. Configure number of obstacles
3. Click "Plan & Run" to start
4. The system will automatically replan when obstacles block the path
