算法格式指南

导入自定义路径规划算法需要遵循以下格式：

1. 类结构要求

class YourAlgorithm {
    constructor() {
        // 初始化代码
    }
    
    plan(grid, start, goal) {
        // grid: 2D数组，0=空闲，1=障碍物
        // start: {x, y} 起点
        // goal: {x, y} 终点
        
        return {
            success: true,
            path: [[x,y], ...],
            time: 0,
            length: 0,
            steps: 0,
            algorithm: '名称'
        };
    }
}

2. 参数说明

参数 说明
grid[y][x] 2D数组，0=空闲，1=障碍物
start.x, start.y 起点坐标（列，行）
goal.x, goal.y 终点坐标（列，行）

3. 完整模板

class MyAlgorithm {
    constructor() {
        // 初始化
    }
    
    plan(grid, start, goal) {
        const startTime = performance.now();
        const path = [[start.x, start.y], [goal.x, goal.y]];
        const length = Math.sqrt(Math.pow(goal.x-start.x, 2) + Math.pow(goal.y-start.y, 2));
        
        return {
            success: true,
            path: path,
            time: performance.now() - startTime,
            length: length,
            steps: path.length,
            algorithm: 'My Algorithm'
        };
    }
}
